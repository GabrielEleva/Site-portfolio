# Eleva Filmmaking — Living Spec

This file mirrors `memory/SPEC.md` for tools that use the lowercase template path. The product is a dark cinematic personal filmmaker portfolio at `/` with event coverage, commercial videos, drone imagery, responsive about/services, filterable work cards, an integrated modal player, WhatsApp CTAs, and a PIN-protected `/admin` dashboard for lightweight work management. The backend is FastAPI + MongoDB under `/api`; the frontend is React/TypeScript with TanStack Query. Four demo videos are seeded, real videos can be added through MP4 URLs or local MP4 upload up to 500 MB with progress, local JPG/JPEG/PNG thumbnails can be uploaded up to 10 MB with preview, and uploaded files are served from `/api/media/{filename}`. Current admin PIN: `2001`.
