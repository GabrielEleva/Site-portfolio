# Eleva Filmmaking — Living Spec

This file mirrors `memory/SPEC.md` for tools that use the lowercase template path. The product is a dark cinematic personal filmmaker portfolio at `/` with event coverage, commercial videos, drone imagery, a filterable aerial/stills photo gallery, responsive about/services, filterable work cards, modal video/photo players, WhatsApp CTAs, and a PIN-protected `/admin` dashboard for lightweight work management. The backend is FastAPI + MongoDB under `/api`; the frontend is React/TypeScript with TanStack Query. Four demo videos and four demo photos are seeded, real videos can be added through MP4 URLs or local MP4 upload up to 500 MB with progress, local JPG/JPEG/PNG thumbnails and gallery photos can be uploaded up to 10 MB with preview, uploaded files are served from `/api/media/{filename}`, and hero/about/services/portfolio/gallery/contact copy is editable from the admin panel through site settings.
